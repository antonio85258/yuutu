# Практическая работа: Sequelize + SQLite

## Предметная область

В работе используется таблица `cars`, содержащая информацию об автомобилях.

## Поля

- `brand` — марка автомобиля, строка, обязательное поле.
- `model` — модель автомобиля, строка, обязательное поле.
- `year` — год выпуска, целое число.
- `price` — цена автомобиля, число с плавающей точкой.
- `isAvailable` — доступен ли автомобиль для продажи, логическое значение.

## Установка

```bash
npm install
```

## Запуск

```bash
npm start
```

После запуска Sequelize подключается к SQLite, создаёт таблицу `cars`, добавляет записи и выводит их в консоль.

Файл базы данных `database.sqlite` не добавляется в Git благодаря `.gitignore`.
